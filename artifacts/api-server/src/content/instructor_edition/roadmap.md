### Notes for planning

- **Git comes late.** The Learning Path says to keep every project in Git from Phase 1 onward, but Git is taught in Chapter 11. Until then, ask learners to keep every project file in one folder, and commit them all once Chapter 11 is done.
- **Exercises.** The Learning Path asks for 5 to 10 small exercises per section. Chapters 1 and 2 have 7 and 8.
- **Practice material.** The Learning Path says practice should come from beyond TutorialsPoint and W3Schools. All exercises and projects here are original.
- **Match-case.** It is now a Phase 2 topic, so it will not appear in the Control Flow chapter.

Phases 2 to 4 and the specialization tracks follow once Phase 1 is approved.
